### Custom Prompt Constructor Pattern (Story 11.6.1)

All pipeline stages follow this pattern for custom prompt injection:

```python
class StageNChain:
    def __init__(self, custom_prompt: Optional[str] = None):
        if custom_prompt:
            logger.info("Using custom prompt template")
            self.prompt_template = PromptTemplate(
                input_variables=["var1", "var2"],
                template=custom_prompt
            )
        else:
            logger.info("Using default prompt template")
            self.prompt_template = get_prompt_template("stage_N")
```
