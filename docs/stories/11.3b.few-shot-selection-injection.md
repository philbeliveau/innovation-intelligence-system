## Acceptance Criteria

1. **Smart Selection**: Retrieve most relevant examples based on brand similarity and recency
2. **Relevance Scoring**: Algorithm weighs brand similarity (60%), recency (30%), quality (10%)
3. **Example Limits**: Configurable max examples per stage (default 3-5)
4. **Prompt Injection**: Examples dynamically added to prompts with token limit awareness
5. **Token Management**: Adjusts example count to stay within model context limits
6. **Format Examples**: Structures examples for optimal LLM consumption
7. **Track Usage**: Logs which examples were used per pipeline run
8. **Performance**: Example retrieval completes in under 100ms
9. **Feature Toggle**: `FEW_SHOT_ENABLED` flag to disable without breaking pipeline
10. **Graceful Fallback**: Pipeline works without examples if none available
