## Story

**As a** innovation team researcher,
**I want** a curation interface to review examples and see which ones improve pipeline quality,
**so that** I can refine the example library and understand what makes outputs successful

## Acceptance Criteria

1. **Usage Metrics**: Track which examples correlate with successful outputs
2. **Database Storage**: Usage statistics saved to database via `PrismaAPIClient`
3. **Correlation Analysis**: Identify which examples improve quality scores
4. **Curation Interface**: Gradio tab for example management
5. **Example Display**: Show examples by stage with usage statistics
6. **Review Workflow**: Interface to edit, remove, or promote examples
7. **Quality Distribution**: Visualize quality scores and usage trends
8. **Example Search**: Filter examples by brand, stage, or quality score
9. **Performance Dashboard**: Show impact of few-shot learning on pipeline quality
