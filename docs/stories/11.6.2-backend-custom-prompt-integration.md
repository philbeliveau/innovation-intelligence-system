## Acceptance Criteria

1. `/run/local` endpoint accepts optional `custom_prompts` dict field in request payload
2. Field structure: `{"stage_0": "Brand enrichment prompt content...", "stage_4": "Custom concept generation prompt..."}`
3. Field is **optional** - if omitted, pipeline uses default templates (backward compatible)
4. Create `backend/pipeline/prompt_file_validator.py` with `PromptFileValidator` class
5. `PromptFileValidator.validate(stage: int, content: str) -> ValidationResult` checks for required placeholders using regex pattern matching (`\{[a-z_]+\}`)
6. Validation result returns: `is_valid: bool`, `missing_placeholders: List[str]`, `error_message: Optional[str]`
7. Server-side validation on request - if validation fails, return **400 Bad Request** with clear message: `{"error": "Invalid custom prompt for Stage 4", "details": "Missing required placeholders: {insights}, {brand_context}"}`
8. Modify 7 stage files in `backend/experimentation/stages/` (`stage_0_enrichment.py` through `stage_6_packaging.py`) to add `custom_prompt_content: Optional[str] = None` parameter to `.run()` method signature
9. If `custom_prompt_content` provided, use it for prompt formatting (skip `load_prompt_template()` and `inject_examples_into_stage_prompt()`)
10. If `custom_prompt_content` is None, use default template loading (existing behavior unchanged)
11. `backend/experimentation/pipeline_orchestrator.py` extracts `custom_prompts` from request payload and passes `custom_prompts.get(f"stage_{i}")` to each stage's `.run()` method
12. Custom prompt content stored **in memory only** during execution (not persisted to `/tmp/runs/`)
13. Progress indicator shows custom prompt usage - status endpoint (`/pipeline/status/{run_id}`) includes field: `{"custom_prompts_used": ["stage_0", "stage_4"]}`
14. Return custom prompts metadata in response for Story 11.6.3 traceability: `{"run_id": "abc123", "custom_prompts_metadata": {"stage_4": {"content_hash": "sha256...", "content_length": 2048, "used_at": "2025-11-24T10:30:00Z"}}}`
15. Gradio UI stores this metadata alongside uploaded file metadata for later database save
16. Metadata only included when custom prompts were actually used
17. Existing pipeline execution unchanged when `custom_prompts` field omitted (default `.md` template files still loaded)
18. If custom prompt formatting fails (e.g., placeholder typo), return 500 error with stage context
19. Existing error handling for LLM API calls unchanged

### PromptFileValidator Implementation Pattern

```python
import re
from typing import List, Optional
from dataclasses import dataclass

@dataclass
class ValidationResult:
    is_valid: bool
    missing_placeholders: List[str]
    error_message: Optional[str]

class PromptFileValidator:
    # Placeholder requirements per stage
    REQUIRED_PLACEHOLDERS = {
        0: ["company_name", "industry", "portfolio"],
        1: ["report_text"],
        2: ["trend_data", "brand_context"],
        3: ["insights", "brand_resources"],
        4: ["insights", "matched_techniques", "brand_context", "no_hallucination_rules"],
        5: ["initiatives", "brand_context"],
        6: ["all_stage_outputs"]
    }

    @classmethod
    def validate(cls, stage: int, content: str) -> ValidationResult:
        """Validate custom prompt content for required placeholders"""
        required = cls.REQUIRED_PLACEHOLDERS.get(stage, [])

        # Extract placeholders from content using regex
        found_placeholders = set(re.findall(r'\{([a-z_]+)\}', content))

        # Check for missing placeholders
        missing = [p for p in required if p not in found_placeholders]

        if missing:
            return ValidationResult(
                is_valid=False,
                missing_placeholders=missing,
                error_message=f"Stage {stage} missing required placeholders: {', '.join(f'{{{p}}}' for p in missing)}"
            )

        return ValidationResult(
            is_valid=True,
            missing_placeholders=[],
            error_message=None
        )
```

### Pipeline Orchestrator Modification Pattern

```python
async def run_pipeline(
    report_text: str,
    brand_profile: dict,
    run_id: str,
    custom_prompts: Optional[Dict[str, str]] = None  # NEW PARAMETER
):
    """Execute 7-stage pipeline with optional custom prompts"""

    results = {}
    custom_prompts_metadata = {}

    for stage_num in range(7):
        stage_key = f"stage_{stage_num}"
        custom_prompt = custom_prompts.get(stage_key) if custom_prompts else None

        if custom_prompt:
            # Generate metadata for traceability
            import hashlib
            content_hash = hashlib.sha256(custom_prompt.encode()).hexdigest()
            custom_prompts_metadata[stage_key] = {
                "content_hash": content_hash,
                "content_length": len(custom_prompt.encode('utf-8')),
                "used_at": datetime.now(timezone.utc).isoformat()
            }

        # Execute stage with custom_prompt_content parameter
        result = await stage_execute_functions[stage_num](
            **stage_inputs,
            custom_prompt_content=custom_prompt
        )

        results[stage_key] = result

    return {
        "run_id": run_id,
        "results": results,
        "custom_prompts_metadata": custom_prompts_metadata if custom_prompts_metadata else None
    }
```
