## Acceptance Criteria

1. **Stage 5 - Competitive Intelligence**: Searches for similar concepts with honesty constraints
2. **Honesty Constraints**: Separates "What we know" vs "What we infer" in competitive analysis
3. **Multi-Query Strategy**: Uses multiple search angles to find relevant concepts
4. **Search Evidence**: Includes URLs and snippets from actual search results
5. **Stage 6 - Opportunity Cards**: Formats concepts into markdown decision cards
6. **Card Structure**: 30-second pitch format (Concept/Insight/Mechanism/Why Now/Why Brand)
7. **No-Hallucination Disclosure**: Every card includes explicit boundary statement
8. **Configuration Management**: All prompts externalized and easily editable
9. **Model Selection**: Stage-specific model configuration via environment variables
10. **Complete Pipeline**: All 7 stages execute end-to-end successfully
11. **Performance**: Complete 7-stage execution in under 10 minutes
