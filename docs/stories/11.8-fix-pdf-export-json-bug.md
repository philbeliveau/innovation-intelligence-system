## Dev Notes

### Root Cause Analysis

The experimentation PDF export module (`backend/experimentation/export/pdf_export.py`) is missing type validation before markdown conversion, causing raw JSON dictionary representation to appear in PDFs.

**Affected Code Location:**
```python
# backend/experimentation/export/pdf_export.py:251-255 (BROKEN)
markdown_content = stage_data.get("markdown", "")
if markdown_content:
    html_content = markdown2.markdown(
        markdown_content,
        extras=["tables", "fenced-code-blocks", "break-on-newline"]
    )
```

**Problem:** When `stage_data.get("markdown")` returns a dict (e.g., from Stage 5), it gets passed directly to `markdown2.markdown()`, which converts it to string representation `{'key': 'value'}`.

**Working Reference Implementation:**
```python
# backend/app/pdf_export.py:160-165 (WORKING)
markdown_content = stage_data.get("markdown", "")
if markdown_content:
    # Type validation BEFORE markdown conversion
    if not isinstance(markdown_content, str):
        import json
        markdown_content = f"```json\n{json.dumps(markdown_content, indent=2)}\n```"

    html_content = markdown2.markdown(
        markdown_content,
        extras=["tables", "fenced-code-blocks", "break-on-newline"]
    )
```

### Technical Context

markdown_content = stage_data.get("markdown", "")

    if not isinstance(markdown_content, str):
