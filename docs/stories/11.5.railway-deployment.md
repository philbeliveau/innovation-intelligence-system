### Railway Deployment Approaches

**RECOMMENDED: Auto-Detection (Nixpacks)**

Railway automatically detects Python projects and builds them using Nixpacks. No Dockerfile required.

**Requirements:**
- `requirements.txt` in root directory (`/backend/experimentation/requirements.txt`)
- Start command: `python gradio_lab.py`
- Root directory: `backend/experimentation`

**Advantages:**
- Simpler setup - no Dockerfile needed
- Railway handles Python environment automatically
- Faster iteration during development
- Automatic dependency caching

**OPTIONAL: Dockerfile Approach**

Use a Dockerfile only if you need advanced build control (specific Python version, custom build steps, multi-stage builds).

```dockerfile
# Use Python 3.11 official image
FROM python:3.11

# Run in unbuffered mode (Railway best practice)
ENV PYTHONUNBUFFERED=1

# Create and change to app directory
WORKDIR /app

# Copy backend directory (includes experimentation/ and app/)
COPY . .

# Install dependencies
RUN pip install --no-cache-dir -r requirements.txt

# Start Gradio app (Railway provides $PORT)
CMD ["python", "experimentation/gradio_lab.py"]
```

**When to use Dockerfile:**
- Need specific Python version not supported by Nixpacks
- Require custom system packages or build steps
- Multi-stage builds for optimization
- Advanced caching strategies

### Brand Profiles Path Resolution

**Current Setup:**
- Gradio code location: `backend/experimentation/gradio_lab.py`
- Brand profiles location: `data/brand-profiles/`
- Current relative path: `../../data/brand-profiles/` (from experimentation folder)

**Railway Root Directory Configuration:**
- Root directory set to: `backend/experimentation`
- This means Railway starts from `/app` and expects files relative to experimentation folder

**Path Resolution:**
```
Railway working directory: /app
Gradio expects: ../../data/brand-profiles/
Resolves to: /app/../../data/brand-profiles/ = /data/brand-profiles/
```

**Problem**: Brand profiles are at `data/brand-profiles/` from project root, but Railway's working directory is `backend/experimentation/`

**Solution**: The relative path `../../data/brand-profiles/` should work correctly:
- Start: `/app` (backend/experimentation)
- Up one: `/` (backend)
- Up two: `/` (project root)
- Down: `/data/brand-profiles/` ✅

**Verification Step**: Test this path resolution during deployment testing.
