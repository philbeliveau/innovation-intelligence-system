1. Add `customPromptFiles` JSONB column to Experiment table with migration script: `ALTER TABLE experiments ADD COLUMN custom_prompt_files JSONB;`
2. Column is **nullable** (existing experiments have NULL)
3. Schema structure: `{"stage_4": {"filename": "stage_4_lactalis_bold_v1.2.md", "uploaded_at": "2025-11-24T10:30:00Z", "file_hash": "abc123...", "file_size": 2048, "file_content": "Full prompt template content..."}}`
4. Modify `save_experiment()` method signature in gradio_lab.py (line 580) to add `custom_prompts: Optional[Dict[str, Dict[str, str]]] = None` parameter
5. Include `custom_prompts` in payload when calling `POST /experiments/save`
6. Modify `save_experiment_wrapper()` in gradio_lab.py (line 1485) to extract custom prompts from `gr.State()` and pass to `save_experiment()` method
7. Custom prompts structure from `gr.State()` includes: `filename`, `uploaded_at`, `content` (backend will add `content_hash` and `used_at` during save)
8. Modify `POST /experiments/save` endpoint to store prompt metadata
9. If custom prompts were included in request: Generate SHA256 hash of each prompt file content, store full metadata (filename, timestamp, hash, size, **full content**) in `customPromptFiles` JSONB column
10. If no custom prompts: Set `customPromptFiles` to NULL or empty JSON `{}`
11. Always store custom prompts even if experiment tagged "Failed" (for debugging)
12. Backend `/experiments/save` endpoint implementation: Accept `custom_prompts` field in request payload (optional), generate SHA256 hash and calculate file size for each prompt, store in `customPromptFiles` JSONB column
13. Display custom prompt indicator in "Experiment History" view: 📝 icon displayed next to experiments that used custom prompts
14. Tooltip on hover: "Custom prompts: Stage 4 (stage_4_lactalis_bold_v1.2.md), Stage 0 (stage_0_enrichment_v2.md)"
15. Experiments without custom prompts show no icon
16. Display custom prompts in experiment details view: New "Prompts Used" section below stage outputs
17. List stages with custom prompts: "Stage 4: stage_4_lactalis_bold_v1.2.md (uploaded 2025-11-24 10:30 AM)"
18. "📋 Download Custom Prompts" button: If 1 custom prompt → download single `.md` file, if 2+ custom prompts → download ZIP with all prompts
19. Create `GET /experiments/{id}/prompts` endpoint: Returns stored prompt file(s) as downloadable `.md` or `.zip`
20. Proper `Content-Type: text/markdown` or `application/zip` header with filename matching original uploaded filename
21. If experiment has no custom prompts → return 404 with clear message
22. Existing Experiment table schema unchanged (additive column only): Existing columns `id`, `run_id`, `timestamp`, `report_text`, `brand_profile`, `stage_outputs`, `quality_tag`, `notes` remain
23. Existing `/experiments/save` endpoint behavior unchanged when no custom prompts: Request without `custom_prompts` field → `customPromptFiles` is NULL
24. All existing experiments queryable with new schema (NULL values handled)
25. Existing "Experiment History" view functionality unchanged: List experiments, filter by quality tag, pagination all work
26. New 📝 icon is **additive** (no impact on existing UI elements)

### Gradio save_experiment() Modification Pattern

```python
async def save_experiment(
    self,
    run_id: str,
    pdf_text: str,
    brand_profile: Dict[str, Any],
    stage_outputs: Dict[str, Any],
    stage_inputs: Dict[str, Any],
    prompts_used: Dict[str, str],
    quality_tag: str,
    notes: str,
    custom_prompts: Optional[Dict[str, Dict[str, str]]] = None  # NEW PARAMETER
) -> str:
    """Save experiment to database with optional custom prompts"""

    payload = {
        "run_id": run_id,
        "timestamp": datetime.now(timezone.utc).isoformat(),
        "report_text": pdf_text,
        "brand_profile": brand_profile,
        "stage_outputs": stage_outputs,
        "quality_tag": quality_tag,
        "notes": notes
    }

    # Include custom_prompts if provided
    if custom_prompts:
        payload["custom_prompts"] = custom_prompts

    async with httpx.AsyncClient() as client:
        response = await client.post(
            f"{self.backend_url}/experiments/save",
            json=payload
        )

    return response.json()["experiment_id"]
```

### Backend /experiments/save Endpoint Modification Pattern

```python
from fastapi import APIRouter, HTTPException
import hashlib
from typing import Optional, Dict

@router.post("/experiments/save")
async def save_experiment(request: SaveExperimentRequest):
    """Save experiment with optional custom prompts metadata"""

    custom_prompt_files = None

    if request.custom_prompts:
        custom_prompt_files = {}

        for stage_key, prompt_data in request.custom_prompts.items():
            content = prompt_data["content"]

            # Generate SHA256 hash
            content_hash = hashlib.sha256(content.encode()).hexdigest()

            # Calculate file size
            file_size = len(content.encode('utf-8'))

            # Store full metadata
            custom_prompt_files[stage_key] = {
                "filename": prompt_data["filename"],
                "uploaded_at": prompt_data["uploaded_at"],
                "file_hash": content_hash,
                "file_size": file_size,
                "file_content": content
            }

    # Insert into database
    query = """
        INSERT INTO experiments (
            run_id, timestamp, report_text, brand_profile,
            stage_outputs, quality_tag, notes, custom_prompt_files
        ) VALUES ($1, $2, $3, $4, $5, $6, $7, $8)
        RETURNING id
    """

    experiment_id = await db.fetchval(
        query,
        request.run_id,
        request.timestamp,
        request.report_text,
        request.brand_profile,
        request.stage_outputs,
        request.quality_tag,
        request.notes,
        custom_prompt_files  # JSONB field
    )

    return {"experiment_id": experiment_id}
```

### Download Endpoint Pattern

```python
from fastapi import Response
import zipfile
from io import BytesIO

@router.get("/experiments/{id}/prompts")
async def download_prompts(id: int):
    """Download stored custom prompts for experiment"""

    # Query database for custom_prompt_files
    query = "SELECT custom_prompt_files FROM experiments WHERE id = $1"
    custom_prompts = await db.fetchval(query, id)

    if not custom_prompts:
        raise HTTPException(status_code=404, detail="No custom prompts found for this experiment")

    # Single file download
    if len(custom_prompts) == 1:
        stage_key, prompt_data = list(custom_prompts.items())[0]
        content = prompt_data["file_content"]
        filename = prompt_data["filename"]

        return Response(
            content=content,
            media_type="text/markdown",
            headers={"Content-Disposition": f'attachment; filename="{filename}"'}
        )

    # Multiple files → ZIP download
    zip_buffer = BytesIO()
    with zipfile.ZipFile(zip_buffer, 'w', zipfile.ZIP_DEFLATED) as zip_file:
        for stage_key, prompt_data in custom_prompts.items():
            zip_file.writestr(
                prompt_data["filename"],
                prompt_data["file_content"]
            )

    zip_buffer.seek(0)

    return Response(
        content=zip_buffer.read(),
        media_type="application/zip",
        headers={"Content-Disposition": 'attachment; filename="custom_prompts.zip"'}
    )
```

### Key Constraints

- Database stores custom prompts even if experiment tagged "Failed" (debugging requirement)
- Full content stored in JSONB (reproducibility requirement, trade-off: larger database size)
- Deduplication is **optional** (same hash → store content once, reference by hash in metadata)
- Migration script is **additive only** (new column, no data deletion)
- Column is **nullable** (existing rows unaffected)
