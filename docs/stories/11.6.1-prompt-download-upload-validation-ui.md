## Story

**As a** CPG innovation founder (Lactalis, McCormick, Decathlon),
**I want** to download default prompt templates, upload customized `.md` files for pipeline stages, and receive immediate validation feedback,
**so that** I can iterate on prompt strategies without writing code and get clear feedback when my prompts are incomplete.

---

## Acceptance Criteria

1. New "📂 Custom Prompts" tab in Gradio UI with two sections: Download Section (7 individual download buttons Stage 0-6 + "Download ALL (ZIP)" button) and Upload Section (7 file upload components)
2. ZIP download includes all 7 default templates (stage_0_enrichment.md through stage_6_packaging.md) + README.md with placeholder documentation
3. 7 file upload components (`gr.File(file_types=[".md"])`) labeled "Stage X Custom Prompt (optional)"
4. File size validation in event handler (max 1MB per file, enforced client-side in upload handler)
5. Help text displayed: "Leave blank to use default prompt"
6. "✅ Validate Uploaded Prompts" button triggers client-side validation
7. Validation checks each uploaded file for required placeholders using regex pattern matching (`\{[a-z_]+\}`)
8. Validation results display per-stage status: ✅ "Stage 4: Valid (filename.md)", ❌ "Stage 4: MISSING placeholders: {insights}, {brand_context}", ℹ️ "Stage 0: Using default prompt (no file uploaded)"
9. Invalid files highlighted in red, blocking pipeline execution
10. Uploaded files persist in `gr.State()` during session
11. File content extraction: When file uploaded via gr.File component, read content with `open(file.name, 'r', encoding='utf-8')`, store in gr.State() with structure: `{"stage_4": {"filename": "stage_4_v1.md", "content": "Full markdown content...", "uploaded_at": "2025-11-24T10:30:00Z"}}`
12. Event handler for file upload updates gr.State() immediately
13. If user uploads new file for same stage, replace existing entry
14. Existing Gradio UI tabs unaffected (Main, Results, Experiment History tabs remain functional)
15. Pipeline execution flow unchanged when no custom prompts uploaded (backward compatible)
16. Modify run_pipeline() method signature (line 440) to add `custom_prompts: Optional[Dict[str, str]] = None` parameter
17. Modify HTTP request to /run/local (lines 487-493) to conditionally include custom_prompts field in payload
18. Modify run_pipeline_wrapper() (line 1385) to extract custom prompts from gr.State() and pass to run_pipeline() method

### Path Resolution Pattern (Multi-Environment Support)

```python
def resolve_prompts_dir() -> Path:
    """Resolve prompts directory across deployment environments"""
    possible_paths = [
        Path("/app/experimentation/prompts"),       # HF Spaces absolute
        Path("prompts"),                             # Local (same dir as gradio_lab.py)
        Path("backend/experimentation/prompts"),    # Project root
    ]
    for path in possible_paths:
        if path.exists():
            return path
    raise FileNotFoundError("Prompts directory not found")
```
