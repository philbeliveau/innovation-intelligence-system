## Acceptance Criteria

1. **Schema Design**: Single experiments table with UUID key and JSONB storage for stage outputs
2. **Required Fields**: run_id, timestamp, report_text, brand_profile (JSONB), stage_outputs (JSONB), quality_tag, notes
3. **Database Support**: SQLite for development, PostgreSQL for production (Railway)
4. **Auto-Migration**: Table created automatically on application startup if not exists
5. **Save Operations**: Store complete pipeline runs with all metadata
6. **Retrieve Operations**: Query by date range, brand, quality tag, or run_id
7. **Filtering**: JSONB queries for brand-specific filtering (industry, geography)
8. **Pagination**: Support for large result sets (configurable page size)
9. **Performance**: Optimized indexes for common query patterns
